# oneliner-roast-agent

One line roasting our own AI agent.

`main.ts` writes the line to `/output/entry.txt`:

> My agent will confidently invent a fact, cite a source that doesn't exist, and then offer to invent three more.

## Run

    node main.ts

It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, else `/output/entry.txt`.
