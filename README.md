# oneliner-roast-agent

## Entry

Turn the roast inward: an agent that invents facts with total confidence, cites sources that never existed, and generously offers to invent three more.

`main.ts` writes it to `/output/entry.txt`:

> My agent will confidently invent a fact, cite a source that doesn't exist, and then offer to invent three more.

## How to run

    node main.ts

The entry lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, otherwise in `/output/entry.txt`.

## Note

No real agent was harmed in this roast — it roasted itself.
